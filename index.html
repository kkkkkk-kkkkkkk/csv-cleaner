How I make a claim like “it’s clean” worth believing

  1. One row, one source. Every output row carries the file and page it came from. If a number looks wrong, you find its origin in one click instead of re-reading the whole stack.

  2. Uncertainty gets a column, not a guess. Anything the parser is unsure about lands in a CHECK column with a reference. The list of questionable cells is part of the deliverable, not hidden inside it.

  3. The cleaning leaves a diff. An issues sheet records row, field, before, after and the rule applied — so a reviewer can verify the work instead of taking my word for it.

  4. The totals have to agree. For financial files I reconcile to the original total and say so on the face of the sheet. If it does not agree, the job is not done — and that is stated plainly rather than buried.

  5. It runs again without me. A single command (or a double-click launcher) reproduces the output from the raw input, so next month’s file does not start a new conversation.

Types of work this covers: scanned PDFs and photographed tables → Excel; duplicate and variant records collapsed on a business key; numbers stored as text; date formats; category control tables; invoice and expense reconciliation; monthly report builds with a refresh button.
