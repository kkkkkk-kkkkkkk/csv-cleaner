# Excel 报表自动化（弹药包 #4）

一句话：**一条命令，把乱表变成 6 页可复核工作簿 —— 汇总全是公式、核对全是公式、改明细自动跟着变、和上期能逐区域对比。**

## 跑法

```bash
python make_sample.py                                            # 生成故意做脏的样例（271 行）
python report.py sample_sales.csv 输出.xlsx                       # 出报表
python report.py sample_sales.csv 输出.xlsx --json 快照.json       # 另存汇总快照
python report.py 本期.csv 输出.xlsx --baseline 上期.json           # 出报表 + 差异页
python report.py 输入.csv 输出.xlsx --title "11月销售报表"
```

输出结构：

| 页 | 内容 |
|---|---|
| 口径 | 源文件、编码、原始/有效/剔除行数、7 条清洗规则、生成时间 |
| 明细 | 全量行 + 源行号 + 清洗标记 + 是否剔除 + 月份；冻结首行、筛选、千分位 |
| 汇总 | **SUMIFS 公式**引用明细：区域 / 月度 / 产品三块，含数量、金额、占比、小计 |
| 核对 | 7 条交叉校验，全部公式，差异必须 0，判定 PASS / FAIL |
| 差异 | 与上期对比：金额、行数、剔除、重复、各区域差额（可选） |
| 图表 | 区域柱形 + 月度折线；产品饼图单独一页（Excel 原生图表，可再编辑） |

## 能力与边界

**处理**：编码自动识别（utf-8-sig / utf-8 / gbk / gb18030）；空行与完全重复行剔除；区域别名归一（`华东区`/`SW`/`North`）；日期 4 种写法；金额剥离 `￥ 元` 千分位与空格，**并区分「千分位逗号」与「小数逗号」**（`1，234.50` → 1234.50，`1234，50` → 1234.50）；数量非正剔除。

**两条硬规矩**：

1. **金额缺失不按 0 计**：空值或非数字的金额行保留在明细、标「未计入合计」、不进任何汇总。否则总额被悄悄拉低，而且没人看得出来 —— 这是最常见的“报表看起来对、其实偏低”事故。
2. **汇总与核对都是公式**：不是脚本算完写死的数字。甲方改一行明细，汇总自己跟着变；怀疑数字不对，核对页 7 条差异全为 0。

## 自验

```bash
python -m unittest test_report -v      # 16 用例
```

实测（`sample_sales.csv`，271 行）：

- 清洗：268 源行 → 空行 3 / 重复 8 / 金额缺失 48 / 数量非正 60 / 区域归一 107 → **有效 171 行，剔除 89 行**
- 汇总：金额 **97,735.00**、数量 **552**、4 区域、6 个月、5 产品
- 核对：**7/7 PASS，差异 0.000**（用 LibreOffice 重新计算后读值，不是脚本自报）
- 差异页：同期子集对比，金额 −26,325.00、行数 −51，四个区域差额逐行列出

## 已知限制

- 列名按中文约定（订单号 / 下单日期 / 区域 / 产品 / 数量 / 金额 / 业务员）；换列名需改 `clean()` 里的键。
- 图表要 Excel / WPS / LibreOffice 打开才渲染，openpyxl 只写图表定义。
- 差异页优先吃 `.json` 快照；给 `.xlsx` 时只有存在缓存值才可用。
